# UC Food Tracker 🍃

A specialized food tracker designed for people with **Ulcerative Colitis** (UC), incorporating anti-inflammatory tracking and **Ayurvedic principles** for gut health.

## Features

### Nutrition Tracking
- **Calories**: Daily target of 1,400 cal (optimized for fat loss at 5'2", 150lb)
- **Protein**: 120g daily target (supports muscle retention during fat loss)
- **Progress bars** with visual feedback

### UC-Specific Metrics
- **Anti-Inflammatory Rating**: Know which foods fight inflammation
- **UC Safety Level**: Safe / Caution / Avoid classifications
- **Flare-friendly guidance**: Identifies foods to avoid during flares

### Ayurveda Integration
- **Dosha classification**: Pitta-pacifying, Vata-pacifying, Kapha-pacifying, Tridoshic
- **Pitta focus**: UC is associated with aggravated Pitta in Ayurveda
- Cooling, soothing food recommendations

## How to Use

1. **Open `index.html`** in any web browser
2. **Search foods** using the search bar
3. **Click to add** foods to your daily log
4. **Track progress** with the visual dashboard
5. **Add custom foods** if something isn't in the database

For a 5'2", 150lb person targeting fat loss:

| Metric | Target | Why |
|--------|--------|-----|
| Calories | 1,400 | ~300-400 cal deficit for sustainable loss |
| Protein | 120g | 0.8g/lb to preserve muscle |

## Key Ayurvedic Principles for UC

1. **Favor Pitta-pacifying foods** - cooling, sweet, bitter
2. **Ghee is gold** - healing for gut lining
3. **Turmeric + ghee + black pepper** - anti-inflammatory trio
4. **Avoid heating foods** - chili, alcohol, caffeine
5. **Eat at regular times** - Pitta thrives on routine

## UC Diet Tips

### During Flares
- Low-residue diet (less fiber)
- Well-cooked vegetables only
- Avoid raw foods
- BRAT diet basics (Banana, Rice, Applesauce, Toast)

### In Remission
- Gradually reintroduce fiber
- Keep a trigger journal
- Small, frequent meals
- Stay hydrated
